# NadamuAuth

Лёгкий, современный и высокопроизводительный плагин авторизации игроков для прокси-сервера **Velocity** (Minecraft).

Спроектирован специально для гибридных (online/offline) сетей серверов: обеспечивает комфортный вход игроков, гибкую мультиязычность и работает на чистой Java со встроенной базой данных без внешних зависимостей.

---

## Основные возможности

- **Ненавязчивый гостевой режим (Вариант A)**:
  Новые (незарегистрированные) игроки сразу попадают в лобби, могут исследовать сервер и получают периодические напоминания о команде регистрации `/r`.
- **Изоляция в NanoLimbo**:
  Зарегистрированные игроки, требующие ввода пароля, изолируются на ультралегковесном сервере NanoLimbo со строгой блокировкой чата и чужих команд до успешного ввода `/login`.
- **Поддержка Forced-Hosts и маршрутизации**:
  Корректно сохраняет целевой сервер игрока при входе по поддомену (`forced-hosts`) после прохождения авторизации. Поддерживает режим единого сервера (`authServer == lobbyServer`) и защиту от ложных киков при падении бэкендов.
- **Безопасная привязка лицензии (`/premium`)**:
  - Игрок запускает проверку лицензии Mojang с окном на 5 минут и 2 попытки с автоматическим откатом при неудаче.
  - Поддержка прямой привязки для новых гостей без необходимости предварительно придумывать пароль.
  - Подтверждённые лицензионные игроки авторизуются через Mojang криптографически в один клик без ввода паролей.
- **Постоянные сессии по IP**:
  Сохранение сессий в базе данных H2 позволяет игрокам с паролем перезаходить без повторного ввода пароля (настраиваемый таймаут, по умолчанию 24 часа). Сессии сохраняются даже при перезапуске Velocity.
- **Мультиязычность и локализация (i18n)**:
  - Автоматическая генерация эталонных словарей: русский (`languages/ru.yml`) и английский (`languages/en.yml`).
  - Автоопределение языка игрока по настройкам клиента (`player.getPlayerSettings().getLocale()`).
  - Возможность добавления любых дополнительных языков (`de.yml`, `es.yml` и т.д.).
  - Интерактивный чат на базе MiniMessage (подстановка команды по клику на `/r `, подтверждение лицензии `/premium confirm`).
- **Встроенная база данных H2**:
  100% чистая Java и пул соединений HikariCP. Никаких внешних сервисов MySQL/PostgreSQL и нативных C++ зависимостей.
- **Высокая безопасность**:
  - Хэширование паролей BCrypt (cost factor 12).
  - Защита от брутфорса со скользящим окном попыток по связке IP + никнейм.
  - Расширяемый интерфейс `AuthService` для подключения внешних провайдеров (Authentik OAuth 2.0 Device Flow).

## Команды и права

| Команда | Алиасы | Права | Описание |
| :--- | :--- | :--- | :--- |
| `/login <пароль>` | `/l` | Всем | Авторизация на сервере |
| `/register <пароль> <повтор>` | `/r`, `/reg` | Всем | Регистрация нового аккаунта с паролем |
| `/changepassword <старый> <новый>` | — | Всем | Смена текущего пароля |
| `/premium [confirm]` | — | Всем | Привязка или проверка лицензии Mojang |
| `/auth reload` | `/nauth reload` | `nadamuauth.admin` | Перезагрузка `config.yml` и всех языковых файлов |
| `/auth unregister <ник>` | `/nauth unregister` | `nadamuauth.admin` | Удаление аккаунта игрока из базы данных |
| `/auth setpremium <ник> <true\|false>` | `/nauth setpremium` | `nadamuauth.admin` | Ручное переключение статуса лицензии игрока |

## Быстрый старт

1. Поместите файл `NadamuAuth-<version>.jar` в папку `plugins/` вашего прокси-сервера Velocity.
2. Убедитесь, что в `velocity.toml` установлен параметр `online-mode = false` (гибридный режим).
3. Убедитесь, что серверы `limbo` и `lobby` зарегистрированы в секции `[servers]` файла `velocity.toml`.
4. Запустите Velocity для генерации конфигурации и языковых файлов в `plugins/nadamu-auth/`.
5. При необходимости скорректируйте параметры в `config.yml` или словари в `languages/`.
