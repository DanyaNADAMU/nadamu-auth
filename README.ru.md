# NadamuAuth

Лёгкий и современный плагин авторизации игроков для прокси-сервера **Velocity** (Minecraft).

## Основные возможности
- **Ненавязчивый гостевой режим (Вариант A)**: Новые (незарегистрированные) игроки сразу попадают в лобби и получают периодические напоминания о команде `/register`.
- **Интеграция с NanoLimbo**: Зарегистрированные игроки изолируются на легковесном сервере NanoLimbo до успешного ввода `/login`.
- **Безопасная привязка лицензии (`/premium`)**: Защита от блокировки игроков. Окно проверки на 5 минут и 2 попытки с автоматическим откатом в оффлайн-режим.
- **Встроенная база данных H2**: 100% чистая Java и пул соединений HikariCP. Никаких внешних сервисов БД или нативных C++ зависимостей.
- **Безопасность**:
  - Хэширование BCrypt (cost factor 12).
  - Защита от брутфорса с временной блокировкой по IP и никнейму.
  - Сохранение сессий по IP (по умолчанию 24 часа).
- **Готовность к Authentik**: Интерфейс `AuthService` позволяет легко подключить внешний Identity Provider (OAuth 2.0 Device Flow).

## Команды
| Команда | Алиас | Права | Описание |
| :--- | :--- | :--- | :--- |
| `/login <пароль>` | `/l` | Всем | Авторизация на сервере |
| `/register <пароль> <повтор>` | `/reg` | Всем | Регистрация нового аккаунта |
| `/changepassword <старый> <новый>` | — | Всем | Смена текущего пароля |
| `/premium [confirm]` | — | Всем | Привязка лицензии Mojang |
| `/auth reload` | `/nauth reload` | `nadamuauth.admin` | Перезагрузка конфигов |
| `/auth unregister <ник>` | `/nauth unregister` | `nadamuauth.admin` | Удаление аккаунта |
| `/auth setpremium <ник> <значение>` | `/nauth setpremium` | `nadamuauth.admin` | Ручное переключение лицензии |

## Быстрый старт
1. Поместите `NadamuAuth-1.0-SNAPSHOT.jar` в папку `plugins/` на вашем прокси Velocity.
2. Убедитесь, что серверы NanoLimbo и Lobby прописаны в `velocity.toml`.
3. При необходимости скорректируйте имена серверов в `plugins/nadamu-auth/config.yml`.
4. Запустите или перезагрузите Velocity.

Подробная документация доступна в [docs/architecture/overview.md](docs/architecture/overview.md) и [docs/ru/setup-guide.md](docs/ru/setup-guide.md).
